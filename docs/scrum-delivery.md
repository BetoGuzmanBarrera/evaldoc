El backlog se infiere de esos entregables y de los prompts del proyecto, pero el repositorio **no documenta** calendario de sprints, ceremonias, estimaciones, velocity, actas ni aceptación firmada. Por tanto no se atribuyen fechas, duración ni personas ficticias. Para una entrega escolar que exija evidencia formal Scrum, el equipo debe anexar sus registros reales. Esta página describe el método iterativo observable, no certifica ceremonias que no se pueden demostrar.
