# Catálogo de 189 materias para las 63 carreras públicas

Origen: Excel EvalDoc_catalogo_7_universidades_63_carreras_189_materias.xlsx, hojas Carreras 63 y Materias 189. Cada carrera se relacionó con la base por institución, campus, código y nombre. No se modifican nombres de carreras.

## Alcance y nivel de evidencia

- 7 instituciones, 21 campus, 63 carreras públicas y 189 materias nuevas: 3 por carrera, 9 por campus, 27 por institución.
- 54 materias en 18 carreras figuran como Materia en plan oficial consultado. Se contrastaron sus nombres con páginas o planes institucionales. No queda confirmada su oferta vigente en cada campus y periodo.
- 135 materias en 45 carreras figuran como Propuesta temática (validar). Denominación exacta, inclusión en plan y oferta por sede/periodo requieren confirmación institucional.
- Los códigos son deterministas e internos; no son claves oficiales.
- QA-BIOT-101 se conserva en DB y Coordinación; el registro público ya no muestra ni solicita ninguna materia. QA-BD01 y su programa histórico no público se conservan.

## Carga y validación local

1. Verificar proyecto local EvalDoc, puerto DB 55422, y respaldo. No ejecutar db reset.
2. Ensayar la migración dentro de una transacción con ROLLBACK y comprobar conteos antes/después.
3. Aplicar solo localmente con npx.cmd supabase migration up --local. La migración verifica 63 relaciones exactas y colisiones antes de insertar; ejecutarla de nuevo no duplica filas.
4. Ejecutar supabase/tests/academic_subjects_catalog.sql y demás suites SQL; después npm.cmd run test, npm.cmd run lint, npm.cmd run build y git diff --check.

## Limitaciones

Las referencias del Excel son heterogéneas. Algunas páginas son fichas generales de carrera y no planes completos. Las 135 propuestas no tienen validación nominal oficial. En las 54 marcadas Plan, la coincidencia del plan general no prueba que una sede específica las imparta actualmente. Cada institución debe confirmar materia, sede, periodo y clave oficial antes de considerar el catálogo curricularmente definitivo. El esquema actual de subjects no guarda un estado de verificación; esta documentación conserva la procedencia.
